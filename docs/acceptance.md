# Live acceptance and capability gaps

## Current evidence

Official API contracts reviewed; deterministic tests and package checks are
separate from native-host acceptance. No installed Marvelous Designer host was
found in the initial local installation audit. License and embedded Python/Qt
version are unknown. No garment has been generated by a real host in this work.

## Required first garment

Use an operator-owned avatar and simple cape or shirt. Back up the source project.
Discover the exact host, load the garment skill, create or import the garment,
simulate bounded steps and record results, save ZPRJ, and export FBX/OBJ plus
Alembic where supported. Record all output hashes, scale, coordinate convention,
frame range/rate, topology and material references. Validate source readback and
an independent process reopening the saved project. Rectangle creation alone
does not constitute a fitted or sewn garment.

Unreal: isolated project import, verify dimensions and material dependencies,
attach or skin to the intended character, test movement/collisions and save/reopen.
Offline GeometryCache playback and Chaos Cloth runtime response are separate gates.

Unity: isolated project import, verify dimensions/materials, character attachment
or skinning, motion/collision checks and save/reopen. Alembic availability is
package-dependent; do not install packages without authorization. Mesh import
does not prove Cloth runtime simulation or skin weights.

## Explicit gaps

- Verified host scheduler/bootstrap and exact Python ABI.
- Native simulation cancellation/progress; no fabricated stop/status API.
- Automatic sewing, avatar fitting, rigging, weight transfer and runtime cloth.
- Animation frame-range capture and export coordinate conventions in a real host.
- Licensed source fixture and both-engine native readback evidence.
- Official catalog/install entry: deferred until a real supported bootstrap and
  release artifact exist. Core is frozen; no Core changes are part of this work.

Do not publish a release or claim catalog availability based on mock tests.

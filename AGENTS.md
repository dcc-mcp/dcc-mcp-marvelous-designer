# Contributor guide

Use DCC-MCP Creator and Skills Creator for adapter and skill changes.
Host APIs must run on the verified host thread. Reuse Core registration,
execution, jobs and cancellation; never expose arbitrary scripts or native calls.
Do not claim real host, Unreal or Unity acceptance from mocks. Preserve dirty
workspaces and garment sources. No vendor assets, credentials or local paths in
public evidence. Commit as loonghao <hal.long@outlook.com> with English
Conventional Commit messages. No release automation until live bootstrap and
licensed-host gates are established.
